# Todo 리스트 (JavaScript 과제)

바닐라 JavaScript로 만든 Todo 리스트입니다. 일정 **추가 · 수정 · 삭제 · 조회**를 지원하고, 새로고침해도 `localStorage`로 데이터가 유지됩니다.

## 시연 영상

https://github.com/user-attachments/assets/8a8a089d-ad05-43a3-80bd-1b098cbaa953

▶ 위 플레이어가 보이지 않으면 [demo/demo.mp4](demo/demo.mp4)에서 내려받을 수 있습니다. (약 31초)

영상 순서: **추가** → **완료 체크** → **수정**(더블클릭 / 연필 버튼) → **조회**(진행 중·완료·전체 필터) → **삭제**(✕ / 완료한 일 지우기) → **새로고침 후 데이터 유지**

## 기능

| 기능        | 사용법                                                                                   |
| ----------- | ---------------------------------------------------------------------------------------- |
| 추가        | 입력창에 입력 후 `Enter` 또는 `추가` 버튼 (공백만 입력하면 버튼 비활성화)                |
| 완료 체크   | 왼쪽 원형 체크박스 클릭 → 취소선 + 진행률 갱신                                           |
| **수정**    | 텍스트를 **더블클릭** 하거나 연필 아이콘 클릭 → `Enter`/바깥 클릭으로 저장, `Esc`로 취소 |
| 삭제        | 항목 오른쪽 `✕` 아이콘, 또는 `완료한 일 지우기`로 일괄 삭제                              |
| **조회**    | `전체` / `진행 중` / `완료` 필터 탭으로 목록 조회                                        |
| 진행률      | 전체 대비 완료 개수와 진행 바 표시                                                       |
| 데이터 유지 | `localStorage` 저장 (손상된 데이터가 있어도 앱이 멈추지 않음)                            |

## 구현 포인트

### 1. 데이터 처리 — 고차 함수 기반의 순수 함수

데이터를 다루는 함수는 DOM을 전혀 모르고, 원본 배열을 바꾸지 않고 **새 배열**을 반환합니다.

```js
const toggleTodo = (list, id) =>
    list.map((todo) => (todo.id === id ? { ...todo, done: !todo.done } : todo));

const removeTodo = (list, id) => list.filter((todo) => todo.id !== id);

const getStats = (list) => {
    const total = list.length;
    const done = list.reduce((count, todo) => count + (todo.done ? 1 : 0), 0);
    const percent = total === 0 ? 0 : Math.round((done / total) * 100);
    return { total, done, percent };
};
```

| 고차 함수 | 사용처                                                 |
| --------- | ------------------------------------------------------ |
| `map`     | 완료 토글, 텍스트 수정, 데이터 → `<li>` 요소 변환      |
| `filter`  | 삭제, 완료 항목 일괄 삭제, 필터 조회, 저장 데이터 검증 |
| `reduce`  | 완료 개수 집계 → 진행률 계산                           |
| `find`    | 수정 대상 조회                                         |

필터는 `FILTERS = { all, active, done }` 객체(이름 → 조건 함수)로 정의해서, 필터를 추가할 때 `if/else`를 건드리지 않고 한 줄만 추가하면 됩니다.

### 2. 동적 UI — DOM 조작과 이벤트

- **DOM 조작**: 데이터(상태)를 먼저 바꾸고 `render()`가 `createElement`로 요소를 만들어 `replaceChildren` / `replaceWith`로 화면에 반영 (상태 → 화면 단방향)
- **XSS 방지**: 사용자 입력은 `textContent`로만 넣어 HTML이 해석되지 않음
- **예외 처리**: 빈 입력·공백 입력, 깨진 JSON, 저장소 접근 불가, 수정 시 빈 값(→ 원복), 저장 데이터의 빈 id·빈 텍스트(→ 제외)·중복 id(→ 새 id 발급)

### 3. 이벤트·성능 최적화

| 최적화               | 내용                                                                                                                                                                           |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **이벤트 위임**      | 항목마다 리스너를 달지 않고 `ul` 하나에서 `change` / `click` / `dblclick` / `keydown` / `focusout`을 처리. 리스너 수가 항목 수와 무관하게 고정되고, 새로 만든 항목도 자동 동작 |
| **일괄 DOM 교체**    | `replaceChildren(...)`으로 목록을 한 번에 교체해 항목마다 `appendChild` 하지 않고 DOM 변경을 한 번으로 모음 (토글·삭제·추가는 목록 전체를 다시 그림)                              |
| **부분 갱신**        | 수정 시작/종료는 해당 `li` 하나만 다시 그리고, 그 안에서도 체크박스 노드는 유지. 전체(또는 체크박스)를 다시 만들면 blur 직후 사용자가 누르던 버튼이 사라져 클릭이 유실되기 때문 |
| **`defer` 스크립트** | HTML 파싱 후 실행되어 `DOMContentLoaded` 래퍼 불필요                                                                                                                           |
| **한글 IME 대응**    | 수정창에서 `event.isComposing` 중의 `Enter`는 무시 (조합 중 글자 중복/누락 방지)                                                                                               |
| **접근성**           | `aria-label`, `aria-pressed`(필터), `role="progressbar"`, 다시 그린 뒤 키보드 포커스 복원 (Space 토글·Enter 삭제/수정 후에도 같은 컨트롤에서 이어서 조작)                       |
